# Research software monitor

Runs the 35 synthetic acceptance-gate regression tests at startup and every six hours; emits a heartbeat every minute and exits on failed checks. No credentials or third-party Python dependencies are required. This is a software-monitoring bootstrap, not the complete ICT strategy, live market monitor, five autonomous LLM roles, or an authorization to trade. Research acceptance stays BLOCKED and execution eligibility stays false.

Test: `python -B monitor_worker.py --once`

Render Background Worker: Docker runtime, repository root directory, Dockerfile `./Dockerfile`. Hosting may incur a recurring charge; obtain a specific cost approval before deployment. Source is public; no research CSVs, personal reports, account credentials or private keys are included. Logs are ephemeral unless durable storage/collection is separately configured.
